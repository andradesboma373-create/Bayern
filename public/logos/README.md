# Папка для логотипов команд / Team Logos Folder

Закидывайте сюда файлы логотипов команд.

### Правила именования:
Файл логотипа должен быть назван **точно так же, как и название вашей команды**, в формате `.png`, `.jpg`, `.jpeg` или `.svg`.
Регистр букв и пробелы игнорируются при сопоставлении.

#### Примеры:
- Если ваша команда называется **NaVi**, назовите файл `navi.png` или `navi.jpg`
- Если ваша команда называется **Virtus.pro**, назовите файл `virtus.pro.png`
- Если ваша команда называется **Team Spirit**, назовите файл `team spirit.png`

Приложение автоматически попробует найти файл с вашим названием команды (без пробелов и в нижнем регистре) в этой папке. Если файл будет найден, он отобразится вместо стандартной текстовой иконки в Симуляторе, в списке команд и в истории матчей!
Если файла нет, отобразится красивая цветная заглушка с первой буквой названия команды.
